# Kovaak's — Digital Parasite Theme

A Kovaak's (FPS Aim Trainer) theme using the Digital Parasite palette.

## Installation

1. Copy `! Sakyuu - Digital Parasite.json` into your Kovaak's themes folder:
   - `.../FPSAimTrainer/FPSAimTrainer/Saved/SaveGames/Themes/`
2. In Kovaak's, go to **Settings → Themes** and select **! Sakyuu - Digital Parasite**.

## Palette.ini

The `Palette.ini` file (located in `Saved/Config/WindowsNoEditor/`) controls the HUD colors. A Digital Parasite version is included in this folder — copy it to `Saved/Config/WindowsNoEditor/Palette.ini` to apply.
