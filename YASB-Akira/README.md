# YASB — Digital Parasite (Akira)

A [YASB](https://github.com/amnweb/yasb) bar based on the [Akira](https://github.com/AmNweb/Akira_YASB) theme by AmNweb, recolored with the Digital Parasite palette. i3WM-inspired: square corners, no rounding, bar positioned at the top with a rose bottom border.

## Installation

1. Install [YASB](https://github.com/amnweb/yasb) (v2.0.7 or newer).
2. Copy `config.yaml` and `styles.css` into your YASB config folder (`~/.config/yasb`).
3. Install the required fonts: **JetBrainsMono Nerd Font Propo** and **Segoe Fluent Icons**.
4. Restart YASB.

## Notes

- The bar is positioned at the **top** of the screen with a rose bottom border (`border-bottom: 1px solid`).
- Square corners, no rounding — matches the angular Digital Parasite aesthetic.
- Adjust `image_path` in `config.yaml` to point to your wallpaper folder.
