# YASB — Digital Parasite (Shibumi)

A [YASB](https://github.com/amnweb/yasb) bar based on the [Shibumi](https://github.com/AmNweb/Shibumi_YASB) theme by AmNweb, recolored with the Digital Parasite palette. Hyprland-inspired layout.

## Installation

1. Install [YASB](https://github.com/amnweb/yasb) (v2.0.7 or newer).
2. Copy `config.yaml` and `styles.css` into your YASB config folder (`~/.config/yasb`).
3. Install the required fonts: **JetBrainsMono Nerd Font Propo** and **Segoe Fluent Icons**.
4. Restart YASB.

## Notes

- Hyprland-inspired layout with Digital Parasite colors.
- Adjust `image_path` in `config.yaml` to point to your wallpaper folder.

Based on Shibumi by AmNweb, recolored with the Digital Parasite palette.
