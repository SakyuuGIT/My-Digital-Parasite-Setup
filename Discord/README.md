# Discord — Digital Parasite

A Discord theme based on [system24](https://github.com/refact0r/system24) by refact0r, recolored with the Digital Parasite palette.

## Installation

1. Install [Vencord](https://vencord.dev/) or [BetterDiscord](https://betterdiscord.app/).
2. Copy `system24-digital-parasite.theme.css` into your themes folder:
   - Vencord: `%APPDATA%/Vencord/themes/`
   - BetterDiscord: `%APPDATA%/BetterDiscord/themes/`
3. Enable the theme in Discord settings.

## Files

| File | Description |
| --- | --- |
| `system24-digital-parasite.theme.css` | Main theme (unrounded corners, Digital Parasite palette) |
| `digital-parasite.css` | Legacy CSS (kept for reference) |

## Notes

- Unrounded corners (`--unrounding: on`) for a sharp, angular look.
- Based on system24 by refact0r.
