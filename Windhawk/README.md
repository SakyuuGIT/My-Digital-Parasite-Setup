# Windhawk — Digital Parasite

Nine [Windhawk](https://windhawk.net/) mod configurations themed with the Digital Parasite palette.

## Installation

1. Install [Windhawk](https://windhawk.net/).
2. Open Windhawk and go to the **Mods** tab.
3. For each mod listed below, import the corresponding `.yaml` file:
   - Click **Import** (or **Advanced** → **Import**).
   - Select the `.yaml` file from this folder.
4. Enable the mods and restart Windows if prompted.

## Mods

| # | File | Mod | Description |
| --- | --- | --- | --- |
| 1 | `Alt-Tab-per-Monitor.yaml` | Alt-Tab Per Monitor | Alt-Tab switcher scoped per monitor |
| 2 | `Middle-Click-to-Close-on-the-Taskbar.yaml` | Middle-Click to Close on Taskbar | Middle-click a taskbar button to close the window |
| 3 | `Resource-Redirect.yaml` | Resource Redirect | Redirect system icons to a custom icon theme (Sweet Paranoia / Rainbow recommended) |
| 4 | `Taskbar-Auto-Hide-Speed.yaml` | Taskbar Auto-Hide Speed | Faster taskbar auto-hide animation |
| 5 | `Taskbar-Tray-System-Icon-Tweaks.yaml` | Taskbar Tray System Icon Tweaks | System tray icon styling |
| 6 | `Windows-11-Notification-Center-Styler.yaml` | Windows 11 Notification Center Styler | Dark panel with rose accents |
| 7 | `Windows-11-Start-Menu-Styler.yaml` | Windows 11 Start Menu Styler | Dark menu with rose hover highlight |
| 8 | `Windows-11-Taskbar-Styler.yaml` | Windows 11 Taskbar Styler | Dark taskbar with rose bottom border (taskbar on top) |

## Notes

- The Taskbar Styler mod expects the taskbar to be positioned at the **top** of the screen. The rose border is rendered at the bottom of the taskbar bar.
- The Resource Redirect mod does not include icon files. Download an icon theme (e.g. [Sweet Paranoia](https://github.com/niivu/resource-redirect-icon-themes)) and point the mod to it.
- Mod configurations were adapted from the Catppuccin Macchiato palette with Digital Parasite colors applied.
