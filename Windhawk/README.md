# Windhawk — Digital Parasite

Nine Windhawk mod configurations themed with the Digital Parasite palette.

## Installation

1. Install [Windhawk](https://windhawk.net/).
2. Open Windhawk and go to the **Mods** tab.
3. For each mod listed below, import the corresponding configuration file.
4. Enable the mods and restart if prompted.

## Mods

| # | Mod | Description |
| --- | --- | --- |
| 1 | Taskbar height and icon size | Adjusted for the Digital Parasite aesthetic |
| 2 | Start menu styling | Rose accent on hover |
| 3 | System tray tweaks | Green status indicators |
| 4 | Window title bar colors | Rose border on active windows |
| 5 | Context menu styling | Dark panel with rose highlight |
| 6 | Explorer accent | Green selection |
| 7 | Notification center | Cyan accents |
| 8 | Volume / brightness OSD | Rose progress bar |
| 9 | Cursor trail | Green trail effect |
