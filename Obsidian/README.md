# Obsidian — Digital Parasite (Cyberpunk)

An [Obsidian](https://obsidian.md/) theme based on [Cyberpunk](https://github.com/nxxxsooo/obsidian-cyberpunk-theme) by nxxxsooo, recolored with the Digital Parasite palette.

## Installation

1. Copy the `Cyberpunk` folder into your vault's `.obsidian/themes/` directory.
2. Open Obsidian → **Settings → Appearance → Themes**.
3. Select **Cyberpunk** from the theme dropdown.
4. Set the accent color to `#ff2d7a` (rose) in **Settings → Appearance → Accent color**.

## Features

- Neon glow on headings (cyan, pink, green, yellow)
- H1 flicker animation (neon sign effect)
- Cyberpunk grid background
- Glitch effects and scanlines
- Rainbow horizontal rules
- Full coverage: callouts, tables, checkboxes, graph view, nav, command palette, tags
- Live preview + reading view support

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Background | `#0a0a12` | Main background |
| Panel | `#12121f` | Sidebar / panels |
| Rose | `#ff2d7a` | Primary accent (H1, links, interactive) |
| Green | `#39ff88` | Success / online (H4, tags) |
| Cyan | `#00e5ff` | Info (H2, code) |
| Yellow | `#ffd93d` | Warnings (H5, highlights) |
| Text | `#e8e6f0` | Primary text |
| Muted | `#6b6880` | Secondary text |
| Border | `#2a2a3f` | Borders / dividers |

## Notes

- Based on the Cyberpunk theme by nxxxsooo (port of channingwalton's Typora Cyberpunk theme).
- Recolored with Digital Parasite palette. Original theme uses cyan/magenta; this version uses rose/green/cyan/yellow.
- The theme is dark-mode only.
