# Wallpapers — Digital Parasite

Wallpapers for the Digital Parasite theme. Place them in your wallpaper folder and point YASB's wallpapers widget to this directory.

## Files

| File | Description |
| --- | --- |
| `Capri wallpaper.jpg` | Capri character wallpaper |

## YASB Integration

In `config.yaml`, set the wallpapers widget `image_path` to this folder:

```yaml
wallpapers:
  type: "yasb.wallpapers.WallpapersWidget"
  options:
    image_path: "D:/Images/Wallpaper YASB/Digital Parasite"
```
