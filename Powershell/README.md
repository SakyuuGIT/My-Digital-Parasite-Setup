# Windows Terminal — Digital Parasite

Windows Terminal color scheme and settings for the Digital Parasite palette.

## Installation

### Option 1: Import color scheme
1. Open Windows Terminal settings (`Ctrl + ,`).
2. Go to **Color schemes** and click **Add new**.
3. Paste the `schemes` section from `settings.json`.
4. Set the default color scheme to **DigitalParasite**.

### Option 2: Replace settings.json
1. Back up your current `settings.json`:
   - `%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json`
2. Copy the `settings.json` from this folder to that location.
3. Restart Windows Terminal.
