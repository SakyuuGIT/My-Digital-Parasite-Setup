# Dark Reader — Digital Parasite

A [Dark Reader](https://darkreader.org/) settings export themed with the Digital Parasite palette. Dark Reader applies a dark mode to any website.

## Installation

1. Install the [Dark Reader](https://darkreader.org/) browser extension (Chrome, Edge, Firefox, etc.).
2. Open Dark Reader settings (click the extension icon → **Settings**).
3. Go to **More** → **Export settings** (or **Import settings**).
4. Import `digital-parasite-darkreader.json`.

Alternatively, you can manually set the colors in Dark Reader's theme settings:

| Setting | Value |
| --- | --- |
| Mode | Dark |
| Background (dark) | `#0a0a12` |
| Text (dark) | `#e8e6f0` |
| Selection color | `#ff2d7a` |
| Brightness | 100 |
| Contrast | 100 |
| Sepia | 0 |
| Grayscale | 0 |

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Background | `#0a0a12` | Dark mode page background |
| Text | `#e8e6f0` | Dark mode text color |
| Rose | `#ff2d7a` | Selection highlight |
| Green | `#39ff88` | — |
| Cyan | `#00e5ff` | — |
| Yellow | `#ffd93d` | — |
| Panel | `#12121f` | — |
| Muted | `#6b6880` | — |

## Notes

- Dark Reader dynamically transforms website colors. The settings file adjusts the dark scheme background and text colors to match Digital Parasite.
- The selection color is set to rose (`#ff2d7a`) for a consistent highlight.
- You can further customize per-site overrides in Dark Reader's settings.
