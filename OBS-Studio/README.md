# OBS Studio — Digital Parasite

A Digital Parasite theme for OBS Studio, based on the Yami Default theme family.

## Installation

1. Download `DigitalParasite.ovt` from this folder.
2. In OBS Studio, go to **Settings → Appearance**.
3. Under **Theme**, select **DigitalParasite**.
4. Restart OBS Studio if prompted.

## Notes

The `.ovt` file is based on the Yami Default theme family, recolored with the Digital Parasite palette. Install it via **Settings → Appearance → Theme**.
