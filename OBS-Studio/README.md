# OBS Studio — Digital Parasite

A Digital Parasite theme for OBS Studio, based on the Yami Default theme family.

## Installation

1. Download `DigitalParasite.ovt` from this folder.
2. In OBS Studio, go to **Settings → Appearance**.
3. Under **Theme**, select **DigitalParasite**.
4. Restart OBS Studio if prompted.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Background | `#0a0a12` | Main background |
| Panel | `#12121f` | Docks / panels |
| Rose | `#ff2d7a` | Accent / active |
| Green | `#39ff88` | Success / live |
| Cyan | `#00e5ff` | Info |
| Yellow | `#ffd93d` | Warnings |
| Text | `#e8e6f0` | Primary text |
| Muted | `#6b6880` | Secondary text |

## Notes

The `.ovt` file is a standard OBS theme archive. Replace the placeholder with your exported theme if needed.
