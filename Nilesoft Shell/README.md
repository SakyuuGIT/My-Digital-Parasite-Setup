# Nilesoft Shell — Digital Parasite

A Nilesoft Shell theme using the Digital Parasite palette. Includes a rose border on context menus.

## Installation

### Scoop installation
1. Install [Nilesoft Shell](https://www.nilesoft.org/) (via Scoop or installer).
2. Copy `theme.nss` to:
   - Scoop: `%USERPROFILE%\scoop\apps\nilesoft-shell\current\imports\theme.nss`
   - Installer: `C:\Program Files\Nilesoft Shell\imports\theme.nss`
3. Restart Windows Explorer (`taskkill /f /im explorer.exe && start explorer.exe`).

### Manual selection
1. Install [Nilesoft Shell](https://www.nilesoft.org/).
2. Open Nilesoft Shell settings.
3. Select **DigitalParasite** as the theme.

## Notes

- The theme includes a rose border around context menus.
- Adapted from the Catppuccin Macchiato palette with Digital Parasite colors applied.
