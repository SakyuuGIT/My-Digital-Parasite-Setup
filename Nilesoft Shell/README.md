# Nilesoft Shell — Digital Parasite

A Nilesoft Shell theme using the Digital Parasite palette.

## Installation

1. Install [Nilesoft Shell](https://www.nilesoft.org/).
2. Copy `theme.nss` into your Nilesoft Shell themes folder.
3. Select **DigitalParasite** in the Nilesoft Shell settings.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Background | `#0a0a12` | Menu background |
| Panel | `#12121f` | Submenu background |
| Rose | `#ff2d7a` | Hover / active |
| Green | `#39ff88` | Success |
| Cyan | `#00e5ff` | Info |
| Yellow | `#ffd93d` | Warnings |
| Text | `#e8e6f0` | Primary text |
| Muted | `#6b6880` | Secondary text |
